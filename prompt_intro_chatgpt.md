# 📋 Texte de présentation pour ChatGPT

## Message d'introduction à envoyer AVANT les prompts

---

**Sujet : Création d'assets pixel art pour un jeu vidéo indie**

Bonjour ! Je développe un jeu vidéo appelé **BeeLaw**, un idle game apicole avec un twist politique. Voici le concept :

> Vous gérez une colonie d'abeilles qui produit du miel. Vous vendez ce miel pour corrompre des députés et faire passer des lois contre les pesticides. Chaque partie est une nouvelle ruche (rogue-like). Le jeu est gagné quand toutes les lois anti-pesticides sont votées.

**Style graphique recherché :**
- Pixel art HD (haute définition, pas pixel grossier)
- Ambiance chaleureuse, colorée, champêtre
- Palette pastel : vert prairie, jaune miel, bleu ciel, marron bois
- Style cartoon mignon mais pas kawaii enfantin
- Public cible : adultes et ados sur Steam

**Consigne importante :**
J'ai besoin que tu génères ~18 assets un par un. Pour chacun, je te donnerai une description précise. À chaque fois, respecte scrupuleusement :
1. La taille indiquée (ex: 64×64, 1920×1080)
2. Le style pixel art décrit ci-dessus
3. Le fond transparent (sauf indication)
4. La cohérence visuelle avec les assets précédents

Je commence par le premier asset dès que tu es prêt. Merci !
